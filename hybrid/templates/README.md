# SchoolSVS HWPX 템플릿 폴더

이 폴더에는 실제 충북 학교폭력 사안처리 A to Z의 HWPX 원본 서식을 둡니다.

## 원칙

- 공식 HWPX 원본을 가능한 한 그대로 사용합니다.
- 프로그램이 문서 전체를 새로 그리지 않고, 원본 내부의 지정 토큰만 치환합니다.
- 서식 개정 시 Python 코드를 수정하기보다 템플릿과 `app/document_registry.json`을 갱신합니다.
- 생성본은 `hybrid/output/`에 저장합니다.

## 1차 템플릿 파일명

- `form03_학교폭력_신고접수대장.hwpx`
- `form10_학교폭력_사안접수보고서.hwpx`
- `form12_학교폭력_사안조사보고서.hwpx`
- `form18_전담기구_심의결과_자체해결.hwpx`
- `form19_전담기구_심의결과_종결.hwpx`
- `form20_학교장_자체해결_동의서.hwpx`
- `form21_학교장_종결처리_동의서.hwpx`
- `form22_학교장_처리결과_보고서.hwpx`

## 토큰 방식

초기 엔진은 HWPX 내부 XML의 텍스트 노드에 아래처럼 토큰을 넣는 방식을 지원합니다.

```text
{{SCHOOL_NAME}}
{{CASE_NO}}
{{RECEIVED_AT}}
{{VICTIM_NAMES}}
{{PERP_NAMES}}
{{INCIDENT_SUMMARY}}
```

각 토큰과 사안 데이터의 연결은 `app/document_registry.json`에서 관리합니다.

## 실제 서식 연결 절차

1. 공식 HWPX 원본을 이 폴더에 넣습니다.
2. 한글에서 자동입력할 위치에 토큰을 삽입한 템플릿 사본을 만듭니다.
3. `/api/documents/inspect?key=문서키`로 토큰을 검사합니다.
4. 시험 사안으로 HWPX를 생성합니다.
5. 한글에서 열어 표·줄높이·폰트·쪽나눔·누락항목을 확인합니다.
6. 원본 서식과 육안 대조가 완료된 문서만 `실사용 가능` 상태로 올립니다.

> 현재는 엔진 기반 단계입니다. 실제 공식 HWPX 원본을 연결하기 전 생성 기능을 실사용 문서로 간주하지 않습니다.
