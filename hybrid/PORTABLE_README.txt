SchoolSVS 학교폭력 업무담당자용 보조프로그램 - 포터블 실행 안내
============================================================

1. 실행
- 압축을 완전히 푼 뒤 최상위 폴더의 "SchoolSVS.vbs"를 더블클릭합니다.
- 별도의 Python 설치가 필요하지 않습니다.
- 프로그램은 127.0.0.1(localhost)에서만 실행되며 사용 가능한 포트를 자동으로 선택합니다.
- Edge 또는 Chrome이 설치되어 있으면 일반 브라우저 탭이 아닌 앱 창 형태로 실행됩니다.
- Edge/Chrome을 찾지 못하면 기본 브라우저에서 실행됩니다.

2. 종료
- 앱 창 방식으로 실행한 경우 창을 닫으면 SchoolSVS Python 서버도 함께 종료됩니다.
- 예외적으로 서버가 남아 있는 경우 최상위 폴더의 "SchoolSVS_종료.vbs"를 더블클릭하면 현재 SchoolSVS 서버를 안전하게 종료합니다.
- "SchoolSVS_진단실행.bat"는 오류 확인이 필요할 때만 사용합니다.

3. 데이터 저장
- 사안 데이터는 외부 서버로 전송하지 않고 현재 PC의 포터블 폴더 안에 저장합니다.
- SQLite 파일: hybrid\data\schoolsvs.db
- 자동 백업: hybrid\data\backups\
- 생성한 문서: hybrid\output\
- 프로그램 창용 브라우저 프로필: hybrid\data\browser-profile\

4. 데이터 안전
- 브라우저 localStorage → SQLite 동기화는 기본적으로 병합 방식이며, 브라우저에 없는 사안을 임의 삭제하지 않습니다.
- 개별 사안 삭제는 SQLite 삭제 전 자동 백업을 생성합니다.
- 브라우저 데이터 전체 비움이 감지되어도 SQLite 전체 삭제는 자동으로 실행하지 않습니다.
- SQLite 데이터를 기존 화면으로 복원할 때는 동기화를 일시 중지하여 복원 중 데이터가 역으로 덮어쓰이지 않도록 합니다.

5. 학교폭력 자료 취급 주의
- 실제 학생정보가 포함될 수 있으므로 프로그램 폴더 자체를 안전하게 관리하십시오.
- USB 등 이동식 저장장치에서 사용할 경우 분실·복제 위험에 주의하십시오.
- 중요한 시점에는 포터블 폴더 전체를 별도 보관하는 것을 권장합니다.
- [서식3] 학교폭력 신고 접수 대장은 충북 A to Z 기준에 따라 수기 작성·수기 결재 대상으로 프로그램이 전자대장을 대신 생성하지 않습니다.

6. HWPX 서식
- 서식10은 실제 2025 HWPX 구조와 2026 A to Z PDF 변경사항을 반영한 적응형 엔진을 사용합니다.
- 관련학생 수에 따라 표 행이 자동 증감하고 조사방식·제2호 조치·즉시분리·폭력유형·타학교·관계회복 항목을 후처리합니다.
- 공식 2026 HWPX가 확보되면 구조검증 후 공식 원본 기반 템플릿으로 교체할 수 있습니다.
- 공식 원본과의 최종 한글 화면·출력 대조 전에는 생성 문서를 반드시 담당자가 확인하십시오.
- 서식12도 별도 구조검증·템플릿 제작 흐름을 지원합니다.

7. 폴더 이동
- SchoolSVS_Portable 폴더 전체를 함께 이동하십시오.
- runtime, hybrid, index.html 중 일부만 따로 복사하면 실행되지 않습니다.
